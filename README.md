# Sample-Portfolio
A sample portfolio website created with HTML/CSS and deployed using Google Cloud Storage.

It allows the user to view information about a fake person. This information includes their biography, skills, learning timeline, hobbies, projects, and resume. Next, there is a contact form that takes your name, email, and message. The website utilizes custom fonts, flexbox and gridbox formatting, and buttons.

Next, it was deployed as a static webpage using the Google Cloud Platform. This allows the website to be accessed in all regions of the US. Finally, this project served as a significant application of the material I learned through my full-stack developer journey. It encompasses all foundational material of the HTML/CSS I have learned and packed it into one webpage.
